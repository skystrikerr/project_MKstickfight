# Lucius Vorenus

Approved low-poly Roman fighter model for Plank Fighter World.

## Files

- `lucius-vorenus-body.glb` — rigid segmented fighter body with the required named pivot hierarchy and hand sockets.
- `lucius-vorenus-shield.glb` — separate blank 20 × 56 scutum. The face is intentionally free of symbols for progression-driven textures.
- `lucius-vorenus-spear.glb` — separate 10 × 167 pilum.
- `lucius-vorenus-gladius.glb` — optional separate sword matching the visual reference; it is not fused to the body.
- `lucius-vorenus.blend` — editable Blender source.
- `lucius-vorenus-hero-preview.png`, `lucius-vorenus-front.png`, and `lucius-vorenus-side.png` — visual QA renders.

## Validation

- Body: 2,364 triangles
- Body dimensions: within the fighter width budget
- Every mesh has UV data
- Materials use the approved shared material names
- No armature, skinning, or animation clips
- No baked emblems, letters, heraldry, or faction symbols
- Weapons and shield are independent GLB assets

# Freydís Eiríksdóttir

Approved low-poly Viking fighter model for Plank Fighter World.

## Files

- `freydis-body.glb` — rigid segmented body with the required fighter hierarchy and hand sockets.
- `freydis-axe.glb` — separate 34 × 60 axe for `OffHandSocket`.
- `freydis-buckler.glb` — separate blank 44 × 44 forearm buckler.
- `freydis.blend` — editable Blender source.
- Preview PNGs provide three-angle and separated-equipment visual checks.

## Validation

- Body dimensions: 34.96 × 15.55 × 116 units
- Body: 2,456 triangles
- Every mesh has UV data
- Materials use only approved shared names
- No skinning, armature, animation clips, symbols, or baked heraldry
- Axe and buckler are independent GLB assets
